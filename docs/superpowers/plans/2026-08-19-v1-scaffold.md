# V1 基础设施与仓库脚手架 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 搭建 zhijin 平台 monorepo 骨架 + 全栈中间件（docker-compose），让三个服务（Kotlin / Python / React）都能启动并连通 Nacos。

**Architecture:** 单仓库（monorepo）承载三个服务：`zhijin-server`（Kotlin + Spring Boot 3 + Spring Cloud Alibaba，Gradle 多模块）、`zhijin-ai`（Python + FastAPI）、`zhijin-web`（React + Vite + antd）。基础设施（PostgreSQL 16 / Redis 7 / Elasticsearch 8 / MinIO / Nacos）用 docker-compose 一键编排。本计划只交付「地基」——服务空壳能跑、能注册、能健康检查，业务逻辑留给计划 B/C/D。

**Tech Stack:** Kotlin 2.0 + Spring Boot 3.2 + Spring Cloud Alibaba 2023.0.1.0 (Nacos) · Python 3.11 + FastAPI + uvicorn · React 18 + Vite + TypeScript + antd 5 · Docker Compose

**设计依据:** `docs/superpowers/specs/2026-08-17-agent-platform-design.md` §3（总体架构）、§4（技术选型）、§5（仓库结构）、§6（模块划分）、§12.1（七大编程原则与可扩展性红线）。

```python
"""AI 服务配置：优先从 Nacos 拉取，失败回退环境变量。"""
import os

from nacos import NacosClient

_NACOS_SERVER = os.getenv("NACOS_ADDR", "127.0.0.1:8848")
_SERVICE_NAME = "zhijin-ai"


def load_config() -> dict:
    """返回服务配置字典。Nacos 不可用时使用本地默认值，保证空壳可独立启动。"""
    default = {
        "app.name": _SERVICE_NAME,
        "log.level": os.getenv("LOG_LEVEL", "INFO"),
    }
    try:
        client = NacosClient(_NACOS_SERVER)
        data = client.get_config("zhijin-ai.yml", "DEFAULT_GROUP")
        if data:
            # V1 空壳仅打日志证明连通；完整解析留给计划 C。
            print(f"[config] 已从 Nacos 拉取 zhijin-ai.yml: {len(data)} chars")
    except Exception as exc:  # noqa: BLE001 - 空壳阶段 Nacos 不可用不致命
        print(f"[config] Nacos 不可用，使用本地默认配置: {exc}")
    return default
```

#!/usr/bin/env bash
# zhijin 全栈冒烟：校验中间件 + 三服务健康端点。
set -euo pipefail

NACOS="${NACOS_ADDR:-127.0.0.1:8848}"
SERVER="${SERVER_ADDR:-127.0.0.1:8080}"
AI="${AI_ADDR:-127.0.0.1:8001}"
WEB="${WEB_ADDR:-127.0.0.1:5173}"

echo "[1/6] Nacos"
curl -fs "http://${NACOS}/nacos/v1/console/health/readiness" && echo

echo "[2/6] PostgreSQL"
docker exec zhijin-postgres pg_isready -U zhijin

echo "[3/6] Redis"
docker exec zhijin-redis redis-cli ping

echo "[4/6] Elasticsearch"
curl -fs "http://localhost:9200/_cluster/health" | head -c 80 && echo

echo "[5/6] 平台服务(8080)"
curl -fs "http://${SERVER}/actuator/health" && echo

echo "[6/6] AI 服务(8001)"
curl -fs "http://${AI}/health" && echo

echo "== 冒烟通过 =="
